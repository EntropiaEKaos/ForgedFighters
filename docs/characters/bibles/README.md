## Shared visual laws
- A fighter must be recognizable from silhouette before costume detail.
- Each fighter owns a distinct movement language and VFX grammar.
- Color alone may never be the only gameplay signal.
- Competitive readability outranks spectacle.
- Body animation never defines authoritative combat timing.
- VFX/camera/audio are presentation layers over deterministic state.
- Skins preserve silhouette-critical anchors and collision truth.
- Every final sprite set must pass the project Definition of Done.

## Bible maturity
**v1:** identity, silhouette, combat fantasy, signature system, animation/VFX language and weaknesses.
**v2:** canonical turnaround, material callouts, facial sheet, exact palette, costume construction and scale chart.
**v3:** complete move visual bible, VFX atlas language, UI portrait/icon package, entrance/victory/taunt and skin constraints.

No mass sprite production begins for a fighter before v2 visual lock. Gameplay greyboxing may begin earlier.
