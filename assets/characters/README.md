# Character Assets

Pasta raiz dos assets de produção dos fighters.

Cada fighter deve manter concept, sprites, VFX, atlas e metadata separados. Arquivos binários finais entram aqui; dados de gameplay permanecem desacoplados e devem referenciar os assets por IDs estáveis.

## Status
- Kael — concept aprovado; produção de sprites/VFX iniciada.
- Demais fighters — concepts em consolidação com a lore antes de canonização.
